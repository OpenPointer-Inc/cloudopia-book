# 🧒 Lesson 1 — What Is Linux?

Imagine your computer is a big house.

Inside the house you have:

* 🗄️ Rooms
* 📦 Boxes
* 📄 Papers
* 👨‍👩‍👧 People
* 🔑 Keys
* ⚙️ Machines

Linux is like the **manager of the house**.

It controls things like:

> "Who can enter this room?"

> "Where is this file?"

> "Which program is running?"

> "How much memory is being used?"

> "Can this computer communicate with another computer?"

Linux is an **operating system kernel**. In everyday conversation, people often say "Linux" to mean an entire Linux-based operating system such as Ubuntu, Debian, or Fedora.

For cloud engineering, Linux is extremely important because **a huge amount of cloud infrastructure runs Linux**.

# 🖥️ Lesson 2 — The Terminal

Normally, you interact with a computer using a graphical interface:

🖱️ Click folder
↓
📂 Open folder
↓
📄 Open file

Linux servers often don't have a graphical interface.

Instead, you use a **terminal**.

You type commands.

For example:

```bash
pwd
```

Linux responds with something like:

```text
/home/alex
```

That means:

> "You are currently standing inside `/home/alex`."

Think of the terminal as **talking to the computer by typing instructions**.

# 🧭 Lesson 3 — Where Am I?

Our first command:

```bash
pwd
```

`pwd` means:

**Print Working Directory**

In simpler words:

> "Computer, tell me where I am."

Try it.

```bash
pwd
```

You might get:

```text
/home/username
```

Don't worry about understanding `/home/username` yet.

We'll get there.

# 📂 Lesson 4 — What's Around Me?

Now type:

> "List what's here."

For example:

```text

```

So if `pwd` tells you:

> 📍 Where am I?

> 👀 What is here?

# 🚶 Lesson 5 — Moving Around

Suppose you're in:

```text
/home/alex
```

And you see:

```text
Documents
Downloads
Pictures
```

You want to enter `Documents`.

You use:

```bash
cd Documents
```

`cd` means:

**Change Directory**

Think:

> 🚶 "Walk into this room."

Now:

```bash
pwd
```

might show:

```text
/home/alex/Documents
```

You moved!

---

# 🏠 Going Back

If you're inside:

```text
/home/alex/Documents
```

and want to go back to:

```text
/home/alex
```

use:

```bash
cd ..
```

`..` means:

> "The directory one level above me."

So:

```text
/home/alex/Documents
                    ↑
                   ..
```

Therefore:

```bash
cd ..
```

takes you back.

---

# 🏠 Going Home

There's another useful command:

```bash
cd ~
```

`~` means your **home directory**.

So no matter where you are:

```bash
cd ~
```

takes you home.

# 🐱 What Is `cat`?

`cat` is short for **concatenate**, but beginners commonly use it to display file contents.

So:

```bash
cat hello.txt
```

means:

> 📖 "Show me what's inside this file."

---

# ➕ Adding More Text

Be careful here.

This:

```bash
echo "Second line" > hello.txt
```

**replaces** the existing contents.

But:

```bash
echo "Second line" >> hello.txt
```

**adds** to the end.

So:

```bash
echo "Hello Linux" > hello.txt
echo "I am learning cloud engineering" >> hello.txt
```

Then:

```bash
cat hello.txt
```

gives:

```text
Hello Linux
I am learning cloud engineering
```

Remember:

```text
>   replace
>>  append
```

This becomes **very important** later when working with logs and scripts.

# 🗑️ Lesson 9 — Delete Something

Suppose we don't want `hello.txt`.

We use:

```bash
rm hello.txt
```

`rm` means:

**remove**

Now:

```bash
ls
```

The file should be gone.

⚠️ **Important:** `rm` is powerful. On Linux, deleting something from the command line usually doesn't send it to a recycle bin.

That's why commands such as:

```bash
rm -rf
```

should never be typed casually.

We'll learn exactly what the options mean before using them.

# 🚚 Lesson 11 — Move / Rename

Try:

```bash
mv backup.txt backup-old.txt
```

Now:

```bash
ls
```

You'll see:

```text
cloud.txt
backup-old.txt
```

`mv` means:

**move**

But it can also **rename** files.

So:

```bash
mv old.txt new.txt
```

basically means:

> "Take `old.txt` and give it the name `new.txt`."
