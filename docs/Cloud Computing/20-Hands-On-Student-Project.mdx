# 🚀 20. Hands-On Student Project Blueprint

Congratulations on making it to the final chapter! 🎉

Now it is time to earn your stripes as a cloud builder. In this hands-on project, you will deploy a **Live Cloud Virtual Machine**, configure security firewall rules, install the **Nginx web server**, and view your very own customized web page live over the public internet!

---

## 🗺️ Project Architecture Blueprint

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 💻 Your Laptop (Web Browser)                                │
  └──────────────────────────────┬──────────────────────────────┘
                                 │ HTTP Request (Port 80)
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 🛡️ Security Group / Firewall (Allow Inbound Port 80 & 22)   │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ ☁️ CLOUD VIRTUAL MACHINE (Ubuntu Linux 24.04 LTS)           │
  │   ┌───────────────────────────────────────────────────────┐ │
  │   │ 🌐 Nginx Web Server Daemon (Active / Running)         │ │
  │   │   └─ Serves: /var/www/html/index.html                 │ │
  │   └───────────────────────────────────────────────────────┘ │
  └─────────────────────────────────────────────────────────────┘
```

## 📋 Step-by-Step Execution Plan

### Step 1: Launch Your Free-Tier Virtual Machine
1. Log in to your cloud console (AWS, Azure, or GCP).
2. Select **Ubuntu 24.04 LTS** as your OS Image.
3. Select the smallest **Free Tier Eligible** shape:
   * **AWS:** `t2.micro` or `t3.micro`
   * **Azure:** `Standard_B1s`
   * **GCP:** `e2-micro`
4. Create and download an SSH key pair (e.g., `cloudopia-key.pem`).

---

### Step 2: Configure Firewall (Security Group) Rules
In your VM’s Network Security settings, verify that two **Inbound Rules** are allowed:

| Type | Protocol | Port Range | Source | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **SSH** | TCP | `22` | `My IP` | Secure remote terminal access |
| **HTTP** | TCP | `80` | `0.0.0.0/0` (Anywhere) | Public website traffic |

---

### Step 3: Connect via Terminal & Install Nginx

Open your terminal or PowerShell on your computer and connect:

```bash
# 1. Set secure permissions on your key
chmod 400 cloudopia-key.pem

# 2. SSH into your cloud virtual machine
ssh -i "cloudopia-key.pem" ubuntu@<YOUR-VM-PUBLIC-IP>
```

Once you are logged into your Linux prompt, run the following commands to update packages and install Nginx:

```bash
# Update package repositories
sudo apt update -y

# Install the Nginx high-performance web server
sudo apt install nginx -y

# Start and enable the Nginx service
sudo systemctl start nginx
sudo systemctl enable nginx
```

---

### Step 5: Test in Your Web Browser! 🌐

1. Copy your VM's **Public IP address** (e.g. `http://54.214.18.90`).
2. Paste it into your Chrome, Safari, or Firefox browser bar.
3. 🎉 Behold your customized cloud website loading live from the cloud!

---

### Step 6: 🧹 Clean Up Resources (Crucial!)

:::caution 🛑 Don't Forget to Clean Up!
Once you take a screenshot of your finished web page to celebrate:
1. Go back to your cloud console.
2. Select your Virtual Machine.
3. Click **Terminate / Delete** to ensure you are never billed for unused compute!
:::
